# HORECA AI Masterclass - Landing Page

Статический лендинг для 2-дневного практического мастер-класса по внедрению ИИ в HORECA.

## Структура

- `index.html` - Главная страница
- `assets/` - CSS, JavaScript и медиа-файлы
- `__manus__/` - Служебные файлы

## Использование

Просто откройте `index.html` в браузере или разверните на любом статическом хостинге (GitHub Pages, Vercel, Netlify и т.д.).

## Технологии

- React 19
- Tailwind CSS 4
- Playfair Display, Unbounded, IBM Plex Sans шрифты
